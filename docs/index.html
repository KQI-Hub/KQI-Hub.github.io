Welcome to the KQI website!

The KQI Hub is a project of Mari's, and the goal is to create simple yet versatile file formats.

The following is a list of formats, systems, and software finished, planned, or in the works:

  • scQOI & scQOI2 - General purpose compression algorithms based on QOI's opcodes.
  • MQIF (.mqif) - A simple GIF clone based on the scQOI compression algorithm, intended as a proof of concept for scQOI (It can come close to GIF for certain images).
  • KQI (.kqi) - An in-progress lossy image format based YCoCg-R, Haar Wavelets, scQOI2, and Huffman Coding.
  • qoicom - A Python implementation of a lossy QOI encoder and decoder.
  • KMI - The reference implementation of the KQI formats.

Why KQI?
KQI is a project designed to make simple yet effective file formats, while they aren't intended to be as efficient as mainstream formats, they are explicitly made to be simple and fairly easy to implement.

What does KQI stand for/mean?
KQI doesn't necessarily mean anything, but the "I" means image. "KQI" came from "JPG", in the same cypher that applying to "PNG" gives "QOI".
